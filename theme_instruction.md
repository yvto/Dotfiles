# Installing icons
I recommend installing icons for better looks of your system, my recommendation is papirus icons. To istall it 
you can type on fedora:
```
sudo dnf install papirus-icon-theme
```
For other icon theme look on github.

# Selecting qt and gtk themes
On linux there are two sorts of apps: qt or gtk. You have to set both of them in order to everything look 
properly. 

### Theme of qt apps
To set theme of qt apps you have to make sure you have installed: qt5ct, qt6ct and kvantum. Then get into 
everyone of the apps listed earlier and change theme manually. You can download additional theme if you like
or change font for better user experience.

### Theme of gtk apps 
To set theme of gtk apps you have to use nwg-look. Open this application and select theme you want 
(my recommendation is catppuccin). You can also add aditional themes if you want. Here also is a place to 
change your font.

# Placement of theme files
Place theme files into `~/.theme` directory. I recommend catppuccin themes.
