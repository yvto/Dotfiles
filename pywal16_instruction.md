# Instalation
To install pywal16 you need to have "pipx". Install it using your package manager, on fedora type:
```
sudo dnf install pipx
```
Then to install pywal16:
```
pipx install pywal16
```
Sometimes you have to add pywal16 to PATH, after you added it you are done here.

# Use
To use pywal 16 all you have to do is choose picture and type one of the few commands in terminal. For example:
```
wal -i /path/to/image
```
To see all of the posibilities type: `wal --help`.
