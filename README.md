# Dotfiles
Bunch of config files for my system.

Everything here is in early stage of developing so there is much of chaos in files. 

# Programs to install
For everything to work properly you have to make sure to install all of application listed below, and configure
them in certain way. Symbol '*' next to the name of program mean that after installation you have to make some
additional actions for program to work as intended, instructions will be listed in section below.
- hyprland *
- hyplock *
- hypridle *
- hyprpaper *
- waybar *
- swaync
- grim
- slurp
- kitty *
- nerd font *
- zsh *
- rofi *
- nautilus
- superfile
- Eye of Gnome (eog) or image viewer
- pipewire
- VLC
- pywal16 *
- qt5ct
- qt6ct
- kvantum
- nwg-look
- nvim *
